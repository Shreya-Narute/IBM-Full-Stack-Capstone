# Cars Dealership Full Stack Application

**Repository Name:** IBM-Full-Stack-Capstone

**Project Name:** Cars Dealership Full Stack Application

## Project Description
A full-stack web application for a car dealership retailer that allows users to view dealership locations and submit reviews.

## Technologies
- Frontend: React
- Backend: Django and Node.js
- Database: MongoDB and SQLite
- Deployment: Docker and IBM Cloud Code Engine
